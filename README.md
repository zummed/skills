# skills

Skills for Claude Code, packaged as a plugin marketplace.

## Install

```
/plugin marketplace add zummed/skills
/plugin install skills@zummed
```

## Skills

| Skill | What it does |
| --- | --- |
| [recast](skills/recast/SKILL.md) | Rebuild a vibe-coded app in a fresh repo from consolidated, improved area specs |

## Adding a skill

Add `skills/<name>/SKILL.md` and a row to the table above.
